FL STUDIO AI COPILOT 0.4.0 — CUMULATIVE DEVELOPMENT SOURCE

NEW: BEFORE / AFTER AUDIO REVIEW
Import matching before/after bounces in Audio lab, then open Audio review.
Confirm the same song range and export settings. The app checks format and timing
without trimming, shifting or resampling. Mismatches/uncertainty get a blocker
report; ready pairs get real level-matched A/B WAVs and measurement reports.
Listen, then save your own preference and notes. No DAW command is applied.

INSTALL / UPGRADE
Use 64-bit Python 3.13. Extract the entire package; run SETUP_WINDOWS.cmd.
First-time dependency installation needs internet access. Run START_DEMO.cmd
first. Demo mixer controls are simulated; imported audio and MIDI exports are real.
For an existing Git checkout: close the companion/MCP clients, run
  git pull --ff-only
  .\SETUP_WINDOWS.cmd
  .\START_DEMO.cmd
For ZIP upgrades, extract into a NEW folder and copy only local-settings.json.
Do not copy .venv, server.json or locks. Existing workspace/audio/journal data
remain in place. The new review database is separate; bridge pins are unchanged.

REVIEW YOUR EXPORTS
1. Export before and after from exactly the same FL song range and settings.
2. Import both in Audio lab. Open Audio review and select baseline/candidate.
3. Confirm matching range/settings; optionally associate a fully verified run.
   The association cannot prove which FL session produced the audio.
4. Analyze. Ready pairs produce A_Baseline_Matched.wav, B_Candidate_Matched.wav,
   and Review_Report.json. Matching uses attenuation only, no EQ or limiting.
5. Listen using A/B switching or the saved WAVs; record a preference explicitly.
   Browser switching preserves approximate position, not phase-accurate alignment.

CONNECT TO FL (UNCHANGED)
Configure a trusted bidirectional virtual MIDI endpoint. Close FL/other PostFader
clients; use CONNECT_FL.cmd if bridge deployment is needed. In FL MIDI settings,
use Universal Bridge with matching input/output port numbers and reload the script.
START_LIVE.cmd > Connection & setup > Check connection > Inspect session.
Pinned PostFader requires FL Studio 2026 build 26.1.3.5336+ and scripting API 44+.
No MIDI driver is bundled. Use a SAVED PROJECT COPY for the existing 1 dB control
test and its separately approved restore before larger operations.

The Plugin workbench still supports high-index discovery and explicit-unit
previews. Stop playback/recording before display searches and approve separately.
The MCP relay now exposes 17 tools. Approval and export-range confirmation require
literal boolean true; numeric 1 is refused. No tool chooses a listening winner.

LIMITS
This is source, not a signed EXE/VST3. No live audio capture, automatic FL render,
Playlist editing, plugin removal/reordering or full adaptive AI mastering exists
in this release. Timing evidence and LUFS/peak measurements are not proof that a
candidate sounds better. Native FL, MIDI, real-plugin and GPU behavior still need
host validation. The same source is tested with synthetic audio, not your projects.

Keep the console open. Stop blocks later work, not an in-flight native command.
Read README.md, BUILD_REPORT.md and docs/AUDIO_REVIEW.md before live use.
