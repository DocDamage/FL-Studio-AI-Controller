Connect your FL session
1. Close FL and other PostFader clients. Run SETUP_WINDOWS.cmd and choose the live adapter.
2. Configure one bidirectional virtual MIDI endpoint. Run CONNECT_FL.cmd, then select Universal Bridge on that input in FL MIDI settings. Match the input and output port numbers.
3. Reload the bridge in FL Script output. Open a disposable project, start START_LIVE.cmd, then Inspect session.
Pinned foundation: PostFader 10.0.0. Its current gate requires FL Studio 2026, 26.1.3.5336+ and scripting API 44+.
Local AI, without Ollama

No model, paid plugin, FL license, MIDI driver, or VST3 binary is bundled. Local-model fit and latency on your GPU are not benchmarked.
Experimental Windows menu adapter
Only exact named entries exposed by a native Win32 Add menu are supported. Custom-drawn menus return a manual handoff instead of blind clicks.
After clicking, focus FL Studio yourself. Keep the main FL window in front and do not move the mouse or type during dispatch. Another window, modal dialog, or changed geometry blocks input.
